# ============================================
# 依赖管理最佳实践
# ============================================
# 
# 开发环境：
#   pip install -r requirements.txt
#
# 生产环境：
#   1. 使用虚拟环境：python -m venv venv
#   2. 激活虚拟环境：source venv/bin/activate (Linux/Mac)
#   3. 安装依赖：pip install --no-cache-dir -r requirements.txt
#   4. 验证：pip list
#
# Docker环境（Phase 2会讲）：
#   COPY requirements.txt .
#   RUN pip install --no-cache-dir -r requirements.txt
#
# 依赖升级策略：
#   - 补丁版本（0.0.X）：可以自动升级（bug修复）
#   - 次版本（0.X.0）：需要测试后升级（新特性）
#   - 主版本（X.0.0）：谨慎升级（可能有breaking changes）
#
# 安全扫描（SRE必备）：
#   pip install safety
#   safety check  # 检查已知安全漏洞
#
# ============================================
# 面试高频问题
# ============================================
#
# Q1: requirements.txt vs Pipfile vs poetry.lock 的区别？
# A: 
#   - requirements.txt：最基础，广泛支持
#   - Pipfile：Pipenv工具，区分dev/prod依赖
#   - poetry.lock：Poetry工具，更现代的依赖管理
#
# Q2: 如何处理依赖冲突？
# A:
#   1. 使用 pip install --upgrade 尝试升级
#   2. 使用 pipdeptree 查看依赖树
#   3. 考虑使用虚拟环境隔离
#   4. 最坏情况：降级某些包或寻找替代品
#
# Q3: 生产环境如何确保依赖安全？
# A:
#   1. 定期运行 safety check
#   2. 使用 Dependabot 自动化依赖更新
#   3. 在CI/CD中集成安全扫描
#   4. 订阅安全公告（如GitHub Security Advisories）
